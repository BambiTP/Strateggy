# Strateggy
A strategy board for TagPro football (egg ball), built on the same engine as [StraTAGy](https://bambitp.github.io/StraTAGy/).

## Features
- **Full Field / Blue Half / Red Half** boards - a half crops the whole board (and exports) to that half
- Red and blue balls (texture-pack sprites) and one egg - drag it onto a ball to pick it up
- Shift+right-click a ball to give it or drop the egg, or toggle Juke Juice, Rolling Bomb, or TagPro
- Tools: Draw, Rectangle, Circle, Line (with arrowheads), Text, Select (move/resize/delete), Pan/Zoom
- Custom color palette (shared with StraTAGy), undo, clear
- Copy or download the current view or the full field as a PNG

## Controls
- N none, D draw, R rectangle, C circle, L line, T text, S select, P pan/zoom
- F full field, [ blue half, ] red half, + / - zoom, 0 fit
- Right click to erase a ball or the egg, right click a text box to edit it
- Ctrl+Z undo, Delete removes the selected drawing
